# Software Installation Requests

## Requesting Software Installation

Employees who need software for work should submit a software installation request through the approved IT support process.

The request should include:

- Employee name
- Employee email
- Software name
- Software version, if known
- Business purpose
- Reason the software is required

## Installation Process

1. Submit a software installation request.
2. Provide the business justification.
3. IT reviews the request.
4. If approval is required, obtain the appropriate manager approval.
5. IT verifies that the software is approved by the organization.
6. IT installs the software or provides approved installation instructions.

## Security

Employees should not download unauthorized or pirated software.

Do not disable antivirus or endpoint security controls to install software.

Only approved software should be installed on company devices.
