# Printer Support

## Office Printer is Not Printing

If an employee cannot print:

1. Verify that the printer is powered on.
2. Check whether the printer shows an error message.
3. Confirm that the computer is connected to the company network.
4. Verify that the correct printer is selected.
5. Check whether the print job is stuck in the print queue.
6. Cancel failed print jobs and try again.
7. Restart the printer if permitted.
8. Contact IT support if the problem continues.

## Print Quality Problems

If printed documents have poor quality:

1. Check the printer's toner or ink status.
2. Verify that the correct paper type is selected.
3. Run the printer's approved cleaning or maintenance option.
4. Contact IT support if the issue continues.

## Security

Do not print confidential documents on unauthorized printers.

Collect sensitive documents immediately after printing.
