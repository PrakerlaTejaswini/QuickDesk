# Shared Drive Access

## Requesting Access to a Shared Drive

Employees who need access to a company shared drive should use the approved access-request process.

The request should include:

- Employee name
- Employee email
- Name of the shared drive
- Folder or resource required
- Business reason for access
- Required access level, if known
- Manager or owner approval, when required

## Access Denied

If an employee previously had access but now receives an access-denied message:

1. Verify that the employee is connected to the company network or VPN.
2. Confirm that the employee is signed in using the correct company account.
3. Check whether the employee's access permissions are still active.
4. Verify whether the shared folder or drive has changed.
5. Contact IT support or the resource owner if access remains unavailable.

## Security

Access should only be granted based on business requirements and organizational policy.

Do not bypass access controls.

Do not share another employee's credentials to access a shared drive.
