# Password Reset Policy

Employees who forget their company password should use the approved password reset process.

The employee should select the password reset option on the company login page and complete the identity verification steps.

Passwords must not be shared with other employees or support agents.

A strong password should be unique and should not contain easily guessed personal information.

If the employee cannot complete the password reset process, they should contact IT support. Support agents should never ask employees to send their existing password through email, chat, or a ticket.
