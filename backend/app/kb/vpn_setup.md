# VPN Setup

Employees can connect to the company VPN using the approved VPN client.

Before connecting, ensure that the laptop has an active internet connection. Open the VPN client and sign in using the company account. Select the appropriate company VPN profile and click Connect.

If the connection fails, restart the VPN client and try again. Employees should record the exact error message if the problem continues.

If the issue still cannot be resolved, contact the IT support team and provide the error message, operating system, and approximate time when the problem occurred.

Employees should not install unofficial VPN software or modify VPN configuration files without IT approval.
