# Employee ID and Access Card Support

## Lost Employee Access Card

If an employee loses an access card:

1. Report the lost card to the appropriate office or security/IT support team immediately.
2. Provide the employee name and identification details requested by the organization.
3. Request that the lost card be disabled if required.
4. Follow the organization's process for obtaining a replacement card.
5. Use an approved temporary access method if one is provided.

## Damaged Access Card

If an access card is damaged:

1. Report the problem to the appropriate support or security team.
2. Provide the required employee identification.
3. Request a replacement card.
4. Follow any required return process for the damaged card.

## Security

Do not lend an employee access card to another person.

Report lost cards as soon as possible.

Do not attempt to modify or bypass access-control systems.
