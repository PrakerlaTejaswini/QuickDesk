# Wi-Fi and Internet Support

## Company Wi-Fi is Not Connecting

If an employee cannot connect to company Wi-Fi:

1. Make sure Wi-Fi is enabled on the device.
2. Select the official company Wi-Fi network.
3. Verify that the employee is using the correct company credentials.
4. Forget the Wi-Fi network and reconnect.
5. Restart the laptop.
6. Check whether other company devices can connect.
7. If the problem continues, contact IT support.

## Internet is Slow

If the company internet connection is slow:

1. Check the Wi-Fi signal strength.
2. Move closer to the approved access point if possible.
3. Disconnect unnecessary devices or applications using the network.
4. Restart the network connection.
5. Check whether the problem affects other websites or applications.
6. Contact IT support if the problem continues.

## Security

Do not connect company devices to unknown or unauthorized networks when handling company information.

Do not share Wi-Fi passwords through public channels.
